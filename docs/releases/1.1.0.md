# ARMM 1.1.0

## Highlights

- Redesigned workspace with clearer version comparisons, alphabetized dependencies, responsive export ordering and a visual link between the selected mod and its detail view.
- Consistent administration tables, action menus and dialogs. Groups show their read and write grants by modset, and audit entries expand to show additional details.
- Sync access has separate **Disable**, **Enable** and **Renew key** actions. Disabling preserves the key and settings, so re-enabling an authorized access can restore existing imports. Renewing invalidates the previous key and requires importing the new configuration. Renew the key if the original authorization can no longer be used.

## Upgrade from 1.0.0

Back up PostgreSQL and the matching `.env`. Keep your existing data volume and `ARMM_SECRET_KEY`, set `ARMM_IMAGE_TAG=1.1.0`, then pull and recreate the ARMM services. No new database migration, service or required environment variable is introduced.

Check application health, sign in, open a modset and verify an existing Sync export if you use Sync access. For earlier releases, see the [upgrade guide](https://github.com/morok101st/Arma-Reforger-Mod-Manager/blob/v1.1.0/docs/upgrading.md).
